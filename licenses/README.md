GNU GPL version 3 text. The CCA-owned source grant permits version 3 or any later

upstream projects, retrieved on 2026-10-13. The original license owners and
copyright statements are retained. The GNU GPL and LGPL reference texts were
retrieved from the official Qt for Python source repository's `LICENSES/`
directory, which carries the standard Free Software Foundation texts.

hashes. A reference copy does not mean that the corresponding dependency is
vendored or redistributed in this source-only repository. The exact installed
dependency packages retain their own licenses and additional component notices.
